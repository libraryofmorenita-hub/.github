### What lives here

**[Kairos](https://github.com/libraryofmorenita-hub)**
A full-stack couples health and fertility tracking application with cycle logging, health analytics, personalized dashboards, and an integrated e-commerce marketplace. Stack: Flutter/SwiftUI, Node.js, PostgreSQL, Supabase, Shopify Storefront API.

**[Ballmecca](https://github.com/libraryofmorenita-hub)**
Co-founded and architected a consumer sports technology platform from the ground up — Firebase backend, reusable component library, real-time data sync, and full brand infrastructure. Improved system performance by 40% and reduced UI bugs by 50%.

**[Morenita Signals](https://github.com/libraryofmorenita-hub)**
End-to-end machine learning data pipeline built in Python — five modular stages: Collect, Clean, Analyze, Model, Serve. Ingests multimodal cultural datasets across Open Library, Met Museum, and MusicBrainz APIs. TF-IDF + cosine similarity recommendation engine deployed via FastAPI.

**[Engineering Projects — MAXINE, ARNOLD, NeuroSect](https://github.com/libraryofmorenita-hub)**
A collection of hardware and research projects: MAXINE (voice-activated hospital bed for quadriplegic patients — 7-channel relay architecture, Embedded C++, clinical validation), ARNOLD (autonomous agricultural rover — motor control, sensor fusion, computer vision), and NeuroSect (multimodal neural decoding simulation — PyTorch, Hugging Face, Bayesian consensus architecture).

**[Muses of Morenita](https://libraryofmorenita-hub.github.io/muses-of-morenita)**
